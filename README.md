# Daily Ink · 每日一墨

给你的 4.2 寸蓝牙墨水屏，每天换一张卡片。

打开网页 → 连接屏幕 → 选一张卡片 → 发送，三步完成。想让屏幕每天自动更新，可以下载 Mac 桌面版。

**👉 在线使用：https://elliezhang893.github.io/daily-ink-zzz/**

---

## 两种用法

| | 🌐 网页版 | 🖥️ Mac 桌面版 |
|---|---|---|
| 安装 | 不用装，打开链接就能用 | 下载 .dmg 安装 |
| 连接屏幕 | 每次在弹窗里手动选择设备 | 自动连接，不弹窗 |
| 每天自动更新 | ❌ | ✅ 到点自动发送，Mac 唤醒后自动补发 |
| 读取「备忘录」做待办卡 | ❌ | ✅ |
| 适合 | 想先试试、偶尔换一张 | 想让屏幕每天自己更新 |

**下载 Mac 桌面版：** 到 [Releases](https://github.com/ELLIEZHANG893/daily-ink-zzz/releases/latest) 页面下载 `.dmg`。M1/M2/M3/M4 等 Apple 芯片选 `arm64`，较早的 Intel Mac 选 `x64`。

## 能做什么

| 卡片 | 说明 |
|---|---|
| 🔮 **运势签** | 输入生日和出生时间，或者直接填四柱八字，生成属于你自己的每日运势：星级、宜忌、幸运色、方位、数字和一句签语 |
| 🐈‍⬛ **每日一句** | 原创小黑猫「墨墨」每天说一句不一样的话，也可以自己写 |
| 📅 **月历** | 整月日历，今天用红圈标出，附农历、干支和节气 |
| ✅ **待办** | 每行一件事，`[x]` 开头表示已完成；桌面版可以直接读取 Mac「备忘录」里的某条笔记 |
| 🚦 **状态牌** | 「专注中」「开会中」「午饭去了」……挂在工位上，一键切换 |
| 💬 **文字卡片** | 写一句想对自己说的话，自动排版 |
| 🖼️ **照片 / 多图轮播** | 上传图片自动裁剪成黑白点阵；选多张可以存进屏幕，让它按间隔自己翻页（实验功能） |

另外还支持切换回屏幕自带的**日历模式**和**清除屏幕**。

预览区显示的就是屏幕上的最终效果，只有黑、白、红三种颜色。三色屏会显示红色点缀，黑白屏上红色会自动变成白色。

## 支持哪些屏幕

使用 **EPD-nRF5 协议**的 4.2 寸（400×300）蓝牙墨水屏，蓝牙名称以 `NRF_EPD_` 开头：

| 驱动 | 颜色 | 测试情况 |
|---|---|---|
| SSD1683 (0x16) | 黑白红三色 | ✅ 作者实测 |
| SSD1683 (0x17) / UC8176 (0x01) / SSD1619 (0x04) | 黑白 | 按协议支持，未实测 |
| UC8176 (0x03) / SSD1619 (0x02) | 黑白红三色 | 按协议支持，未实测 |

连接后，页面会显示你的屏幕型号。如果提示「未支持的驱动」，欢迎在 Issues 里告诉我型号。

## 怎么用

### 网页版

1. 用 **Chrome 或 Edge** 打开上面的链接（iPhone 请用 App Store 里的 **Bluefy** 浏览器）。
2. 点 **连接**，在弹窗里选择 `NRF_EPD_` 开头的设备。
3. 选一种卡片，填好内容，右边会实时预览。
4. 点 **发送到墨水屏**。屏幕会闪烁十几秒，这是正常的刷新过程，期间请不要断开。

> 小提示：同一时间只能有一个设备连接屏幕。如果手机或其他网页连着它，电脑就搜不到。

### Mac 桌面版

1. 下载 `.dmg`，双击打开，把 **Daily Ink** 拖进「应用程序」。
2. **第一次打开：** 本项目是个人开源作品，没有购买苹果开发者签名，所以 macOS 会提示「无法验证开发者」。处理方法：
   - 打开「系统设置 → 隐私与安全性」，在页面下方找到 Daily Ink，点 **仍要打开**；
   - 如果提示「已损坏，无法打开」，打开「终端」运行下面这行，再重新打开 App：
     ```
     xattr -cr /Applications/Daily\ Ink.app
     ```
3. 第一次连接时，macOS 会询问蓝牙权限，点 **允许**。
4. 在第 4 步「每日自动更新」里勾选开启，设定时间和卡片类型。卡片内容使用对应标签页里填好的设置。
5. 关闭窗口后，App 会留在屏幕顶部的菜单栏（小黑猫图标）继续工作。想让它开机自动运行，勾选「开机时自动启动」。

**关于自动更新：** Mac 睡眠时 App 不会运行，唤醒后会自动补发当天的卡片。想准时更新，可以让 Mac 每天定时唤醒（在终端运行，`09:58` 换成比发送时间早两分钟）：
```
sudo pmset repeat wakeorpoweron MTWRFSU 09:58:00
```

**读取备忘录待办：** 在「待办」标签页填好笔记标题，第一次读取时 macOS 会询问是否允许 Daily Ink 控制「备忘录」，点 **好**。笔记里每行一件事即可。

## 隐私

所有计算都在你自己的电脑里完成，包括生辰八字、照片处理和备忘录读取。**不会上传到任何服务器。** 表单内容只保存在本机，方便下次打开。

## 常见问题

**连接时找不到设备，或者一直连不上？**
屏幕同一时间只接受一个连接：先断开手机、网页或其他脚本。这类屏幕响应比较慢，常常要试好几次才连得上，App 会自动重试，请耐心等一会儿。还不行就把电脑蓝牙关掉再打开。

**发送后屏幕全黑或花屏？**
重新发送一次。如果仍然不正常，请在 Issues 里附上页面底部「运行日志」的内容。

**多图轮播最多几张？**
由屏幕固件的图片槽位数决定，连接后会显示在「电量 / 图片槽位」里。作者的 4.2 寸三色屏是 **15 张**，超出的部分不会存入。

**多图轮播怎么停？**
在「照片」标签页点 **停止轮播**，屏幕会停在当前画面。之后正常发送任何卡片即可。

**运势签准吗？**
仅供娱乐。算法按八字日主强弱判断喜用五行，再结合当天干支的十神关系和冲合推算，是简化的传统命理思路，不构成任何建议。
