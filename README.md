# Daily Ink · 每日一墨

给你的 4.2 寸蓝牙墨水屏，每天换一张卡片。

打开网页 → 连接屏幕 → 选一张卡片 → 发送，三步完成。不用装任何软件，不用写代码。

**👉 在线使用：https://elliezhang893.github.io/daily-ink-zzz/**

---

## 能做什么

| 卡片 | 说明 |
|---|---|
| 🔮 **运势签** | 输入生日和出生时间，按八字和当天干支生成每日运势：星级、宜忌、幸运色、方位、数字和一句签语 |
| 🚦 **状态牌** | 「专注中」「开会中」「午饭去了」……挂在工位上，一键切换 |
| 💬 **文字卡片** | 写一句想对自己说的话，自动排版 |
| 🖼️ **照片** | 上传任意图片，自动裁剪并转换成墨水屏能显示的黑白点阵 |

另外还支持切换回屏幕自带的**日历模式**和**清除屏幕**。

预览区显示的就是屏幕上的最终效果，只有黑、白、红三种颜色。三色屏会显示红色点缀，黑白屏上红色会自动变成白色。

## 支持哪些屏幕

使用 **EPD-nRF5 协议**的 4.2 寸（400×300）蓝牙墨水屏，蓝牙名称以 `NRF_EPD_` 开头：

| 驱动 | 颜色 | 测试情况 |
|---|---|---|
| SSD1683 (0x16) | 黑白红三色 | ✅ 作者实测 |
| SSD1683 (0x17) / UC8176 (0x01) / SSD1619 (0x04) | 黑白 | 按协议支持，未实测 |
| UC8176 (0x03) / SSD1619 (0x02) | 黑白红三色 | 按协议支持，未实测 |

连接后，页面会显示你的屏幕型号。如果提示「未支持的驱动」，欢迎在 Issues 里告诉我型号。

## 怎么用

1. 用 **Chrome 或 Edge** 打开上面的链接（iPhone 请用 App Store 里的 **Bluefy** 浏览器）。
2. 点 **连接**，在弹窗里选择 `NRF_EPD_` 开头的设备。
3. 选一种卡片，填好内容，右边会实时预览。
4. 点 **发送到墨水屏**。屏幕会闪烁十几秒，这是正常的刷新过程，期间请不要断开。

> 小提示：同一时间只能有一个设备连接屏幕。如果手机或其他网页连着它，电脑就搜不到。

## 隐私

所有计算都在你的浏览器里完成，包括生辰八字和照片处理。**不会上传到任何服务器。** 表单内容只保存在你自己的浏览器里，方便下次打开。

## 常见问题

**连接时找不到设备？**
确认屏幕有电，并且没有被手机或其他页面连着。可以关掉其他连接，或者把电脑蓝牙关掉再打开。

**发送后屏幕全黑或花屏？**
重新发送一次。如果仍然不正常，请在 Issues 里附上页面底部「运行日志」的内容。

**运势签准吗？**
仅供娱乐。算法按八字日主强弱判断喜用五行，再结合当天干支的十神关系和冲合推算，是简化的传统命理思路，不构成任何建议。
